## Перед сдачей

- [ ] Каждый обязательный пункт имеет проверяемое доказательство.
- [ ] Решение запускается по README из нового терминала; пути не завязаны на чужой ноутбук.
- [ ] Указаны происхождение данных, очистка, схема проверки, метрика и ограничения.
- [ ] Числа в слайдах совпадают с результатами зафиксированного прогона.
- [ ] Формат submission совпадает с образцом: колонки, ID, порядок, тип предсказания.
- [ ] Секреты, исходные данные и служебные файлы не попадают в публичную сдачу.
- [ ] Сохранены локальное демо, видео, PDF/слайды и отправленная версия.
- [ ] Получено подтверждение приёма до дедлайна.
