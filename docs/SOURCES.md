# Источники и границы подготовки

Проверено 16.10.2026, время Астаны / Алматы.

- [Datathon ’26](https://datathon.com.kz/ru): дата, команда 2–4, партнёры, раскрытие датасета на старте. Текущую доступность регистрации и свой статус нужно проверить в аккаунте.
- [Расписание](https://datathon.com.kz/ru/schedule): check-in 09:00–11:00, Orange Hall; открытие 11:00; работа 17.10 12:00 — 18.10 12:00; питчи с 13:00, закрытие 18:00. Залы работы и питчей ещё помечены как уточняемые.
- PDF пользователя `How to Win the Datathon.pdf`, 30 страниц: стратегия, подготовка, требования, питч; в `docs/WORKSHOP_REVIEW.md` указаны страницы. Это источник рекомендаций, а не полный регламент.
- [Логотип партнёра](https://datathon.com.kz/partners/forte.svg): оригинальный SVG сохранён в `assets/forte.svg`, основной цвет из файла `#A31551`. [Сайт Forte](https://forte.kz/ru) использован для проверки визуального контекста. Шаблон не является официальным шаблоном банка.
- [uv](https://docs.astral.sh/uv/): управление Python, lock-файл и окружение; документация дополнительно сверена через Context7.
- [CatBoost Python](https://catboost.ai/docs/en/concepts/python-usages-examples): fit/eval_set, категориальные признаки и сохранение моделей; сверено через Context7 и фактический запуск.
- [scikit-learn model selection](https://scikit-learn.org/stable/modules/cross_validation.html) и [метрики](https://scikit-learn.org/stable/modules/model_evaluation.html): group/time-проверка и трактовка метрик; сверено через Context7.

Не установлены: точный кейс, схема данных, официальные веса оценки, состав жюри, длительность питча, правила заранее подготовленного кода, внешних API и данных. Никакие цифры учебного набора не характеризуют ForteBank. Публичную страницу Telegram не удалось прочитать через web-инструмент; её содержимое не использовалось для выводов.
