## Первый час после раскрытия

Открой `docs/REQUIREMENTS.md` и перепиши туда каждый пункт задания. Зафиксируй целевую метрику, способ сдачи, время питча, запрет/разрешение внешних API, данных и заранее подготовленного кода. В воркшопе готовый каркас отмечен **IF ALLOWED**; его использование на соревновании нужно сверить с объявленными правилами.

Не начинайте с большого приложения. Сначала определите единицу наблюдения, какое решение принимает пользователь и что будет считаться улучшением. Затем зафиксируйте разбиение данных, получите baseline и выберите один сценарий, который можно показать целиком.

## Как выделиться среди команд с ИИ

Выберите один результат, который жюри сможет проверить за минуту: конкретный сегмент с подтверждённым эффектом, исправленная ошибка простого подхода, удачная обработка сложного случая или та же точность при меньшей цене решения. У результата должны быть исходные данные, сравнение, метод проверки и видимое последствие для пользователя. Подробный порядок — `docs/AI_WORKFLOW.md`.
